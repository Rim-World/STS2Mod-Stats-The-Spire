# Stats the Spire (本地版) — STS2 数据分析 Mod

**版本**: 1.9.0
**适用**: Slay the Spire 2 v0.111.1 与 v0.113.1
**依赖**: 必须安装完整的 `STS2-RitsuLib 0.6.14` 或更新兼容版本
**依赖说明**: RitsuLib 可能向自身作者发送遥测；本 Mod 不发起网络请求。可在 RitsuLib 设置中管理遥测。
**类型**: 纯信息展示，不影响游戏平衡。本 Mod 无网络，完全离线。

---

## 这个 Mod 做什么？

Stats the Spire（本地版）是杀戮尖塔 2 的纯离线数据分析工具。展示药水掉落概率、敌人意图状态机、战斗内贡献分解、个人生涯统计等，帮助你在爬塔时做出更好的决策。

**无网络。无服务器。全部数据来自本地。**

---

## 功能一览

### Infomod — 局内信息

**药水机会追踪**

顶部栏上的指示器跟踪当前的药水掉落几率。悬停可看到精英战掉落概率；持有「白兽雕像」时显示 100%。

**问号房间显示**

悬停于未走过的问号房间上，看到下一个问号房间会发生什么的全部概率列表。影响问号遭遇概率的遗物也被纳入计算。

**卡牌掉落几率**

顶部栏上的指示器查看下一场战斗奖励的单张卡牌出率，按当前进阶与稀有度补偿计算。Boss 战只显示「Boss奖励：稀有100%」；极速模式隐藏。

**商店价格**

悬停于未走过的商店房间上，显示下一家商店的预期价格，包括普通、罕见、稀有与「商店」稀有度遗物。价格采用颜色区分，轻松判断是否可以用当前金币购买。影响商店价格的遗物也被纳入计算。

### Intent Graph — 怪物 AI 可视化

将怪物意图显示为状态机。鼠标悬停在怪物上，可以看到其意图状态机。多段攻击的攻击图标按总伤害选档；初始分支按实际槽位或遭遇变体显示。

**意图** — 显示怪物下次的行动。

**意图组** — 用蓝色方框框起来的一组意图，是怪物下次所有可能的行动。左上角：概率。右上角：最多连续使用次数。

**意图变化** — 总是从"初始"意图开始，沿黄色箭头去下个意图或意图组。

### 战斗贡献统计图

**每场战斗结束后自动弹出**（Ctrl+F8 开关），展示本场战斗中每张卡牌、遗物、药水的贡献：

**全局汇总**额外包含**治疗**分类。

**特色**：
- 卡牌、遗物、药水在同一图表中混合排序
- **间接伤害追踪**：中毒、易伤增伤等归因到施加该效果的卡牌
- **力量/修饰器归因**：力量加成归给提供力量的来源，而非攻击牌
- **防御追踪**：FIFO 格挡归因 + 敏捷加成 + 虚弱减伤 + 缓冲/无实体减伤
- **抽牌 / 能量获取**独立显示各来源贡献
- **药水贡献**正确归因
- **子条形图**：变形/生成的卡牌以缩进子条显示在来源卡下方
- **升级贡献**：战斗内升级带来的额外伤害/格挡以橙色段标识
- **实时更新**：战斗中打开面板可看到实时贡献数据

#### 详细贡献计算说明

##### 伤害怎么分配

**直接伤害**归打出它的卡牌。

**力量加成**归给你加力量的牌，不归攻击牌。

**易伤加成**同理，归给施加易伤的来源。

**多来源叠加时按比例分**。

**中毒、荆棘、火焰屏障等间接伤害**归给最初施加该能力的牌。

##### 防御怎么计算

伤害从大到小经过五个层次的减免：
1. **减敌人力量** — 归给减力量的牌
2. **敌人身上的减益**（虚弱等）— 归给施加减益的来源
3. **无实体** — 归给施加无实体的来源
4. **格挡** — 按产生顺序（FIFO）消费
5. **缓冲** — 归给施加缓冲的来源

##### 其他规则

- **自伤**：以红色段显示在防御栏中，不计入防御百分比
- **战斗内升级**：升级带来的额外伤害/格挡归升级来源，显示为橙色段
- **充能球归因**：被动伤害归产生者；额外激发归激发者

##### 颜色说明

| 颜色 | 含义 |
|---|---|
| **蓝色** | 直接伤害 / 直接格挡 |
| **紫色** | 修饰器加成（力量、易伤、敏捷等） |
| **橙色** | 升级带来的增量（如武装升级其他牌） |
| **红色** | 自伤 |
| **金色条** | 遗物贡献 |
| **青色条** | 药水贡献 |
| **绿色条** | 治疗贡献 |

### 全局贡献汇总

按 **Ctrl+F8** 可随时打开贡献面板，包含两个标签页：

| 标签 | 内容 |
|------|------|
| **本场战斗** | 当前（或最近）一场战斗的详细贡献 |
| **本局汇总** | 本次 Run 所有战斗的累计贡献 |

### 个人生涯统计

进入 **百科大全 → 角色数据 → 个人生涯统计** 查看本地所有 RunHistory 的聚合数据：

- **胜率汇总卡片**：数据范围 / 进阶 W-L / 进阶胜率 / 最高连胜
- **胜率趋势**：最近 10 / 50 / 100 / 全部 局滚动胜率
- **死因排行**：按遭遇战的死亡原因排行
- **卡组构筑 + 路线统计**：每 Act 平均卡牌获取 / 购买 / 删除 / 升级、小怪 / 精英 / ? 房间 / 商店 / 火堆数
- **先古遗物选取率**：按 Elder 分组，每个池子的遗物选取率 / 选取次数 / 胜率 / 胜率浮动
- **Boss 战损**：全部 Boss 的平均 HP 损失 + 死亡率
- 角色筛选：全部角色 / 单个角色

### 历史记录本局统计

进入 **历史记录详情**，点击 **本局统计** 按钮，会同时打开左右两个窗口：

- 左侧：角色 · 进阶 · 楼层 · 胜负
- 左侧：卡组构筑 / 路线统计（每 Act 表格）
- 左侧：先古遗物选取
- 左侧：Boss 战损
- 右侧：本局所有战斗的贡献统计
- 两窗等宽并居中；右窗右上角的关闭键同时关闭两窗；Esc 和点击遮罩也可关闭

### 卡牌图书馆 / 遗物收藏个人统计

在 **百科大全 → 卡牌图书馆 / 遗物收藏** 中，每张卡牌 / 遗物的详情面板显示你的个人样本数 + 选取率 + 胜率 + 升级率 + 删除率 + 购买率，全部来自本地历史局聚合。

```
%AppData%/sts2_community_stats/
├── contributions/
│   └── {StartTime}_{seed}/            # 每局独立目录
│       ├── meta.json
│       ├── combat_{floor}_{sequence}.json
│       ├── summary.json
│       ├── live.json
│       ├── shop_purchases.json
│       └── shop_offers.json
```

1.4.4 及更早的 `{seed}_*.json` 文件会只读回退，不会自动移动或改名。v0.113.1 已用种子 61111 连续两局验证目录隔离；v0.111.1 用种子 91111 验证 StartTime 目录。

1.5.2 起，Mod **不会自动清理**贡献数据；旧版 90 天清理已删除。需要清理时请自行备份并手动删除对应目录。

## 安装

1. 先安装完整的 `STS2-RitsuLib` 模组文件夹到 `mods/`。不能只复制根 DLL。
2. 将 `sts2_statsthespire_local` 文件夹放入游戏目录的 `mods/` 文件夹。
3. 启动游戏，Mod 会按 manifest 中的依赖顺序加载。

> **只保留一个副本。** 本地版与旧创意工坊版共用 ID `sts2_statsthespire_local`。如果创意工坊原版仍在订阅列表中，先取消订阅或禁用。只取消本地版的勾选不会禁用创意工坊副本。

## 常见问题

**Q: 这个 Mod 会影响游戏平衡吗？**
A: 不会。Mod 标记为 `affects_gameplay: false`，仅显示信息。

**Q: 这个 Mod 需要联网吗？**
A: 不需要。这是本地版——所有数据来自你的本地历史记录，完全不需要网络连接。

**Q: 为什么个人数据显示 0 样本？**
A: 你可能还没有足够的历史局数据。多打几局，数据就会累积起来。Mod 分析你保存的 `.run` 文件。
