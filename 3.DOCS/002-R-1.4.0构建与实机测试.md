## 已知问题

- 启动早期 `RunHistoryAnalyzer` 在 `SaveManager` 初始化前调用，记录 `InitProfileId must be called on SaveManager!`。后续生涯页加载会重试并成功，未导致崩溃。可在后续版本增加延迟重试，减少警告。
- 用户设置中 `contribution_panel=false`、`intent_state_machine=false`，因此自动显示与意图面板未在实机默认路径触发。测试通过测试探针直接调用验证。
- 测试使用 AutoSlayer 种子 12345，可能影响游戏当前局存档。用户已有存档备份。
- Mod 启动时的正常清理逻辑删除了 1315 个超过 90 天的贡献文件；这是既有设计行为。
