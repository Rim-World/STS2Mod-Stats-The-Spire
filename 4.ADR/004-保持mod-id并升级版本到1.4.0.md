# 保持 Mod ID 并升级版本到 1.4.0

- 状态：已接受
- 日期：2026-11-19
- 当时项目版本：1.4.0
- 相关文件：`9.SRC/manifest.json`、`9.SRC/src/Config/ModConfig.cs`

## 背景

旧包使用 `id=sts2_statsthespire_local`，数据目录为 `%AppData%/sts2_community_stats`。本项目要兼容旧设置和旧统计缓存，同时区分新构建。

## 决策

保持 Mod ID、程序集名和数据目录不变。把 manifest 与代码内版本升级到 `1.4.0`。本阶段不发布新的 Workshop 物品。

## 备选方案

### 改用新 ID

否决理由：会切断旧设置、旧缓存和用户数据；游戏内会出现两个 Mod 条目。

### 保持 1.3 版本号

否决理由：无法区分旧 DLL 与新构建，版本日志和问题定位会混乱。

## 后果

- 获益：升级路径连续；旧数据可读。
- 代价：如果未来与原 Mod 同时安装，ID 冲突；发布前必须确认加载顺序或改用新 ID。
- 规则：发布新 Workshop 物品时重新评估 ID；本阶段不得同时部署旧包和新包。
