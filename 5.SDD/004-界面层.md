## 依赖

允许：

- `UI -> Collection`：读取统计快照。
- `UI -> Config`：读取语言、开关、面板尺寸。
- `UI -> Util`：读取名称、图标、布局、异常隔离。

禁止：

- `UI` 不得调用 Harmony 或直接修改游戏模型。
- `UI` 不得写贡献 JSON；持久化由 `Collection/Util` 负责。
- `UI` 不得在 `_Process` 中做重计算；重计算放在采集层或后台任务。

静态检查：

```bash
rg -n "Harmony|AccessTools|Patch" 9.SRC/src/UI
rg -n "File\.Write|Directory\.Create" 9.SRC/src/UI
```

## 布局与交互

- 贡献面板默认右侧，可拖动标题栏移动。
- 右下角手柄由 `ResizablePanel` 处理，尺寸写入 `ModConfig.PanelWidth`/`PanelHeight`。
- 尺寸受最小值和视口边界限制。
- 跑局历史双窗以 680×900 两窗、16 间距为基准；按视口宽高分别缩放并居中，高度目标为视口 83%。
- 右侧回放窗口设置左上锚点、固定位置与尺寸，并设置 `sts_replay_window` 元数据；拖动与缩放处理器忽略该元数据。
- 右侧回放窗口关闭或左窗关闭时，`ContributionPanel.Hide` 恢复实时锚点、保存尺寸与保存位置。
- 右侧回放窗口的关闭键通过 `ShowRunReplay` 传入的回调请求 `CloseOpenPopup`；实时贡献面板的关闭键只隐藏自身。
- 贡献面板热键默认 `Ctrl+F8`，由 `HotkeyRegistration` 注册，可在 RitsuLib 设置页重绑定。
- 设置页由 RitsuLib 提供；F7 自绘面板已删除。
- 设置变更后统一保存开关、面板位置与尺寸，并刷新顶部指示器和意图面板；语言不保存到 Mod 设置。
- 语言由游戏语言决定；设置页不提供语言项；README 与设置页说明写明改语言后重启游戏。
- 意图面板缩放由 `ModConfig.IntentPanelScale` 控制，范围 0.5–1.25。

## 状态与生命周期

- 面板单例懒创建；场景树变化时由入口延迟挂载。
- 战斗结束面板自动显示；下一次战斗开始时重置。
- 跑局历史弹窗在 `NRunHistory.OnSubmenuHidden` 或 Esc 时关闭；Esc 由 `EscapeCloseControl` 消费。
- `RunHistoryPatch.CloseOpenPopup` 关闭左窗时同步隐藏右侧回放面板；右窗关闭键调用同一路径，两窗同时关闭。
- 左窗不显示关闭键。右窗关闭键在回放模式下请求 `CloseOpenPopup`，清除 `sts_replay_window` 并释放左窗。
- 贡献面板在退局、放弃、保存退出、新局时隐藏；隐藏必须清空 `_replayRunData`。
- 战败请求 `CombatManager.LoseCombat` 时立即隐藏意图面板。
- 语言由游戏语言决定；Mod 不订阅语言事件。改语言后重启游戏，贡献面板、设置页与生涯页重新创建并换字。
- 意图面板在目标死亡、失焦、战斗结束时隐藏。
- 地图悬停面板由 `MapPointPatch` 登记与清理；UI 只负责面板内容，不负责地图节点生命周期。

## 失败与降级

- 图标或纹理加载失败时使用文本/空图标，不抛出。
- 节点已释放时检查 `IsInstanceValid`/`IsInsideTree`。
- 面板定位失败时回退到默认位置。
- 尺寸恢复失败时使用 fallback 尺寸。

## 1.7.2 本地化名称解析

`NameLookup.TryLookup` 负责把 `SourceId` 转为显示名称。1.9.0 起只使用游戏当前语言的官方词表：

- `ToDisplayText`：移除 `[img]`、`[color]`、`[lb]` 等 BBCode，替换 `{MelodyWaText}`、`{MelodyChoText}`、`{MelodyKiText}` 与 `{MelodyWa}` 等占位符。
- `FormatDisplayText`：读取 raw 标题判断旋律占位符；图像-only 显示缺少文字时，用 raw 文本重建标题。
- `MelodyShortName`：按当前 Mod 界面语言返回 `哇`/`啾`/`叽` 或 `Wah`/`Cho`/`Ki`；这是图像-only 的兜底文本。
- 英文名表与英文 `_fallback` 优先路径已删除；当前词表查不到时返回原始 ID。
- UI 调用点不直接拼接 BBCode。负责范围：显示名称；不负责本地化模组注册、SmartFormat 扩展或游戏标题生成。第三方模组缺失时，`GetFormattedText` 返回原文，行为与 1.7.1 一致。

## 1.8.1 双窗布局

- `RunHistoryStatsSection` 只负责左侧单局统计：摘要、卡组构筑、路线、先古选取、Boss 战损；不再创建贡献按钮。
- `RunHistoryPatch` 计算左右矩形：基准两窗均 680、间距 16、高 900；宽高分别按视口限制缩放，窗口组居中对称。
- 左窗删除关闭键；标题字号 30；左右外边距 18；分节内边距 16；表格列距 16；数值列最小宽度 64。
- 右侧窗口由 `ContributionPanel.ShowRunReplay(summary, turns, position, size, closeAction)` 创建；它只显示本局汇总页，空数据时显示 `contrib.empty_run`。
- 左窗真实 49 层内容高度 799，滚动页高 799；在 1920×1080 下无纵向滚动。
- 右窗 `?` 与 `✕` 均为 40×40、18 号字、2 像素亮色边框；帮助键深蓝、关闭键深红。关闭键调用 `CloseOpenPopup`，两窗同时关闭。
- 回放期间隐藏右下缩放手柄；`DraggablePanel` 与 `ResizablePanel` 通过 `ContributionPanel.ReplayWindowMeta` 跳过输入。
- 负责范围：双窗几何、按钮样式与回放布局隔离；不负责统计字段、图表归因和历史 JSON。

## 1.8.2 双窗回放热键保护

- `ContributionPanel.Toggle` 在读取可见性前检查 `ReplayWindowMeta`；元数据存在时直接返回。
- 该路径不调用 `Hide`、`ClearReplayWindow`、`RefreshTabs` 或 `UpdateDps`，因此不会隐藏右窗、留下左窗或重建实时内容。
- `ReplayWindowMeta` 只由 `ShowRunReplay` 设置；`Hide` 与 `ClearReplayWindow` 清除。
- 双窗关闭后元数据不存在，热键恢复实时面板开关；实时面板关闭键仍只隐藏自身。
- 负责范围：双窗期间的贡献面板热键拦截；不负责热键绑定、双窗几何、统计字段和历史 JSON。

## 1.8.3 默认热键 Ctrl+F8

- `ModConfig.ContributionPanelHotkey` 默认值为 `Ctrl+F8`；`HotkeyRegistration.DefaultBinding` 与非法绑定回退值相同。
- 既有 `mod_prefs.json` 中的 `contribution_panel_hotkey` 优先，不自动迁移；只有用户明确要求时才改本地值。
- 设置页说明、面板帮助和 README 的默认值同步为 `Ctrl+F8`。
- 热键注册、重绑定、文本输入/控制台抑制和双窗回放保护均由原有实现继续负责。
- 负责范围：默认值与本地配置迁移；不负责其他 Mod 的按键分配或全局冲突仲裁。

## 1.9.1 历史入口按钮

- `RunHistoryPatch.CreateEntryButton` 统一创建「本局统计」入口按钮；1.9.2 起尺寸为 `350×75`，字号为 `33`，左上位置为 `(30, 210)`。
- 按钮锚定 `NRunHistory` 左上角，不加入 `MarginContainer`；不使用容器拉伸。
- 按钮文本包含 `📊` 与 `L.Get("run_hist_btn")`；图标随字号放大。
- 点击按钮仍调用 `OpenPopup`，左右双窗几何不变。
- 负责范围：入口按钮的创建与尺寸；不负责双窗几何、统计字段和历史 JSON。

## 1.9.2 按钮宽度收窄

- 1.9.1 的 `390` 宽度在实机中左右空白偏多；1.9.2 收窄到 `350`。
- 高度 `75`、字号 `33` 和位置 `(30, 210)` 不变。
- 探针分别验证矩形尺寸和点击后的双窗。

## 1.7.3 回放 DPS 与先古名称

- `ContributionPanel` 增加回放专用的伤害与回合字段。回放模式不读取实时 `CombatTracker`，避免空的实时计数器产生 `—`。
- `RunHistoryStatsSection.CountCombatTurns` 从游戏 `.run` 的 `MapPointHistory[*].Rooms[*].TurnsTaken` 汇总回合数，传入 `ContributionPanel.ShowRunReplay`。
- `NameLookup.Event` 在 `events` 表未命中时回退 `NameLookup.Ancient`；`VAKUU`、`PAEL` 等先古事件使用 `ancients` 表或内置中英文名称。
- 负责范围：回放数字与事件显示名称；不负责改写历史 JSON、修正旧能量记录或解析未提供的回合数据。
