# 语言自动跟随游戏

- 版本：1.9.0
- 日期：2026-11-23
- 关联需求：RQ-028
- 关联计划：`2.PLANS/032-M-语言自动跟随游戏.md`
- 关联决策：`4.ADR/009-语言只跟随游戏并在重启后刷新.md`

## 1. 结论

1.9.0 已实现自动语言：

- `zhs` 与 `zht` 使用简体中文界面。
- 其他游戏语言使用英文界面。
- 游戏术语名称只使用游戏当前官方词表，不优先使用英文名表，不使用英文兜底表。
- RitsuLib 设置页不再提供语言项。
- `mod_prefs.json` 的旧 `language` 值被忽略。
- 语言改动后需要重启游戏；Mod 不订阅运行中语言变化。

## 2. 实现

- `L.Current` 从 `LocManager.Instance.Language` 推导；`LocManager` 未初始化时回退到 `TranslationServer.GetLocale()`。
- 中文判定覆盖 `zhs`、`zht` 与以 `zh` 开头的 locale。
- 删除 `ModConfig.Language`、设置页语言下拉项、`ModConfig` 的语言读写、`L.LanguageChanged` 与 `ContributionPanel.RefreshText`。
- `NameLookup` 删除英文名表、英文优先分支与 `_fallback` 优先反射路径；当前词表缺失时返回原始 ID。
- `IntentStateMachinePanel` 统一通过 `NameLookup.Monster` 取名称。
- 设置页描述和 README 写明「语言跟随游戏；更改游戏语言后重启游戏」。

测试探针临时加入 `CommunityStatsMod.Initialize`，等待 `LocManager` 后输出当前语言、界面标题、设置页说明、卡牌名称与先古名称。测试后已删除探针，并确认最终 DLL 不含 `LangProbe` 字符串。

| 游戏语言 | locale | Mod UI | 标题 | 卡牌 `STRIKE_FOOL` | 先古 `VAKUU` | 日志 |
|---|---|---|---|---|---|---|
| `zhs` | `zh_Hans` | `CN` | `Stats the Spire — 设置` | `打击` | `瓦库` | `8.TEST/1.9.0/langprobe-zhs-stdout.log` |
