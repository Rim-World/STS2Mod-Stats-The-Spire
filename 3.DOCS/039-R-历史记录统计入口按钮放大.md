# 历史记录统计入口按钮放大

- 文档编号：039-R
- 日期：2026-11-25 03:45
- 版本：1.9.1
- 相关需求：RQ-029 / AC-030
- 结论：v0.111.1 无头按钮探针 PASS；双版本 Release 构建 0 错误；安装与最终加载通过。用户图形界面视觉未验证；v0.113.1 运行未做。

## 背景

用户完成 1.9.0 人工验收后，要求把跑局历史页的「本局统计」入口按钮放大到当前尺寸的 1.5 倍，并要求字体同步放大。当前按钮为 `260×50`，字号 `22`；目标为 `390×75`，字号 `33`。

## 改动

### 入口按钮

- `RunHistoryPatch` 增加固定尺寸参数：左 `30`、上 `210`、宽 `390`、高 `75`、字号 `33`。
- 抽出 `CreateEntryButton()`；`InjectButton` 只在按钮不存在时调用它，再挂到 `NRunHistory`。
- 按钮继续锚定左上角，不加入 `MarginContainer`；`CustomMinimumSize` 与目标尺寸一致。
- 文本保持 `📊  <本局统计>`，图标随字号放大。

### 未改动

- 双窗几何仍为 `680×900 + 16 + 680×900`，在 1920×1080 下居中。
- 右窗帮助键、关闭键、图表内容不变。
- 统计字段、JSON、历史数据、归因和实时贡献面板不变。
