# v1.5.0 在 v0.113.1 的设置、热键与同 seed 隔离测试

- 测试时间：2026-11-20 00:24 至 01:10
- 测试对象：`sts2_statsthespire_local.dll` 1.5.0
- 游戏：Slay the Spire 2 v0.113.1（`release_info.json`，提交 `d09d48e5`）
- 基础库：STS2-RitsuLib 0.6.14（Workshop 安装）
- 方式：本机无头启动、RitsuLib 设置探针、AutoSlayer、历史探针、生涯探针
- 数据目录：`%AppData%/sts2_community_stats`

## 结论

1.5.0 在 v0.113.1 通过构建、加载、RitsuLib 设置页注册、主菜单入口、热键注册与重绑定、同 seed 两局隔离、历史回放与 legacy 回退。v0.111.1 运行时验证尚未执行。

## RitsuLib 设置页

探针输出：

```text
[SettingsProbe] pages=1
[SettingsProbe] page id=settings title=Stats the Spire — 设置 sections=2 entries=11 visibleOnHosts=All
[SettingsProbe] open-main-menu success=True code=requested deferred=True
```

条目数为 11：语言 1、意图面板缩放 1、贡献面板热键 1、功能开关 8。页面没有重复条目。

绑定回调与持久化：

| 操作 | 结果 |
|---|---|
| 语言写为 `EN` | `ModConfig.Language=EN`，`L.Current=EN` |
| 语言恢复为 `CN` | 保存后 `mod_prefs.json` 为 `CN` |
| 意图面板缩放写为 `1.0` | `ModConfig.IntentPanelScale=1.00` |
| 缩放恢复为 `0.8` | 保存后 `intent_panel_scale=0.8` |
| `PotionOdds` 开关取反 | `ModConfig.Toggles.PotionOdds` 同步变化 |
| `PotionOdds` 恢复 | 保存后 `potion_odds=true` |

| 项目 | 第一局 | 第二局 |
|---|---:|---:|
| StartTime | 1795107016 | 1795107502 |

| 合并后的贡献键数 | 64 | 64 |
| 商店购买 | 14 | 14 |
| `live.json` / `shop_offers.json` | 结束后删除 | 结束后删除 |

第二局启动日志为：

```text
[RunDataCollector] BeginNewRun 1795107502_61111 (start=1795107502, seed=61111)
[RunLifecycle] new singleplayer run: 1795107502_61111
```

第二局没有出现 `ResumeRun`，没有加载第一局的 live、商店购买或商店报价。两局商店购买文件内容相同，是因为同 seed 生成同一条商店路径；文件位于不同 StartTime 目录，购买数均为 14，没有叠加成 28。

历史探针输出：

```text
[HistoryProbe] seed=51111 start=1795093263 win=True floor=49 sources=75 identity=1795093263_51111
[HistoryProbe] seed=61111 start=1795107016 win=True floor=48 sources=64 identity=1795107016_61111
[HistoryProbe] seed=61111 start=1795107502 win=True floor=48 sources=64 identity=1795107502_61111
```

同日 seed 的两条历史分别解析到不同 StartTime 和不同贡献目录。种子 51111 的新目录不存在，日志出现：

```text
[ContributionPersistence] using legacy summary for seed=51111
```

legacy 只读回退成功，返回 75 个来源键。
