## 1. 代码改动

### 1.1 卡牌概率

- `9.SRC/src/UI/CardDropOddsIndicator.cs`：删除固定基础值，运行时读取 `CardRarityOdds.RegularRareOdds`、`EliteRareOdds` 与对应罕见常量。
- 负补偿按游戏的阈值顺序计算：稀有阈值先加偏移，罕见阈值再加稀有阈值；偏移为负时罕见也随之下降。
- Boss 房间只显示一行「Boss奖励：稀有100.0%」。
- `BigGameHunter` 存在时，精英列改为稀有 100%、罕见 0%、普通 0%。
- `9.SRC/src/UI/CardDropOddsIndicator.cs` 与 `Localization.cs`：副标题改为单张卡牌出率，删除「至少出现一张」。

### 1.2 药水概率

- `9.SRC/src/UI/PotionOddsIndicator.cs`：保留原始当前值，顶部显示夹到 0；精英行使用原始值加 12.5 个百分点。
- 删除悬停面板的 2/3/4/5 场累计行与 `CumulativeOdds`。
- `9.SRC/src/Patches/CombatUiOverlayPatch.cs`：读取 `Hook.ShouldForcePotionReward`；「白兽雕像」等强制奖励显示 100%。
- `9.SRC/src/Patches/CombatUiOverlayPatch.cs`：在 `RewardsCmd.GenerateForRoomEnd` 后刷新，奖励界面显示新当前值。

### 1.3 商店价格

- `9.SRC/src/UI/ShopPricePanel.cs`：新增「商店」稀有度遗物行，基础 200 金币、上下浮动 15%。
- 基础随机价格先取整；会员卡、送货员折扣与删牌费按游戏十进制结果转整数截断。
- `9.SRC/src/Patches/MapPointPatch.cs`：价格与金币取本地玩家；本地玩家缺失时不再回退到第一名玩家。
- `9.SRC/src/Patches/MapPointPatch.cs` 与 `ShopPatch.cs`：删牌使用后重建已打开的商店悬停面板。
- 极速模式的商店悬停面板不创建。

### 1.4 未知房间

- `9.SRC/src/UI/UnknownRoomPanel.cs`：上一房间包含商店时，从可选集合移除商店；释放的份额进入事件。
- 不使用 `RunManager.BuildRoomTypeBlacklist` 的「全部子节点为商店」分支，避免 U2 的飞翼靴误判。

### 1.5 意图状态机

- `9.SRC/src/UI/IntentStateMachinePanel.cs`：攻击图标的伤害档位改为 `单次伤害 × 重复次数`。
- 扭动虫按实际槽位决定「生成」后继：1/3 到污秽啃咬，2/4 到扭动。
- 小啃兽单分支显示「独自一人」，双分支保留「正面/背面」。
- 啃咬机按运行时 `ScreamFirst` 显示「先猛夹」或「先尖叫」，不再写死号位。
- 英文条件文本改为字面 `<`，删除 `&lt;`。
- 外骨骼虫 4 号位保留；伤害数字仍为设计意图值。

### 1.6 先古遗物与名称

- `9.SRC/src/Util/AncientPoolMap.cs`：黄金印移到特兹卡塔拉池 3；沙堡移到欧洛巴斯池 2；补齐涅奥两个池；修正达弗幕限制为多幕；动态补充的正面分支同时从诅咒池移除。
- `9.SRC/src/Collection/RunHistoryAnalyzer.cs` 与 `RunHistoryStatsSection.cs`：先古选择 ID 去掉角色后缀，海玻璃按 `SEA_GLASS` 聚合。
- `9.SRC/src/Util/NameLookup.cs`：先古名称先查 `ancients` 表，回退改为官方中文；死因也查 `ancients`。
- `9.SRC/src/UI/CareerStatsSection.cs`：Boss 幕号改用 `ActModel.Index`，不再按 `ModelDb.Acts` 列表下标。
- `9.SRC/src/Util/CareerStatsCache.cs`：缓存 schema 升到 2，旧缓存自动丢弃并重建，避免旧的先古 key 继续显示。
