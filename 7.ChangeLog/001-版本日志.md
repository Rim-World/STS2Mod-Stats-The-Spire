## 1.4.1 — 2026-11-19 08:05

- 开发人员反馈概括：补充愚者历史记录与筛选；改为单一 DLL 同时兼容 v0.111.1 与 v0.113.1；在个人 fork 提交源码。
- 实装更改概括：
  - 生涯角色列表从 `ModelDb.AllCharacters` 动态生成，包含愚者。
  - 愚者角色、卡牌、遗物名称使用游戏本地化文本。
  - 角色筛选只统计本地玩家。
  - 对局模式按名称匹配，并动态显示恐惧、极速或自定义。
  - 卡牌生成钩子按运行时签名注册；移除版本编译常量。
  - 版本号升级到 `1.4.1`。
- 简略技术细节：
  - 不引用愚者类型；v0.111 的 `AllCharacters` 只有 5 个角色时自动省略愚者。
  - `GameMode` 数值：v0.111 `Custom=3`，v0.113 `Dread=3`；因此禁止按整数匹配。
  - 卡牌生成钩子：v0.111/v0.113 均为 `(ICombatState, CardModel, Player?)`。
  - 单一 DLL 构建 0 错误、7 个可空引用警告。
- 测试结果：
  - 愚者历史：15 局、13 胜、2 负；平均卡组 25.7、平均遗物 13.3。
  - 名称：`STRIKE_FOOL=打击`、`FOOLISH_SHOT=愚蠢射击`、`SONG_BOW=歌曲之弓`。
  - 角色下拉：`所有角色`、5 个基础角色、`愚者=6`。
  - 模式下拉：`全部`、`随机种子`、`恐惧`、`极速`、`每日挑战`、`多人模式`。
  - UI 探针：愚者生涯区块创建成功，子节点 7。
  - 卡牌生成钩子：`patched combat-state signature`，无失败警告。
- 失败经验/实验教训：
  - 只用 `#if` 切换版本 API 会生成不同 DLL，违背单文件要求。
  - 编译期常量缺失时，旧分支可能调用不存在的属性；构建成功不等于运行补丁正确。
  - 必须先核对运行时方法参数数量，再注册 Harmony 补丁。
