# 1.8.1 双窗等宽与关闭键微调

- 日期：2026-11-23 01:23
- 适用版本：1.8.1
- 相关需求：RQ-025 / AC-026
- 结论：v0.113.1 游戏内布局探针 PASS；双版本 Release 构建 0 错误；发布门禁 12/12 PASS；1.8.1 已安装并通过加载检查。用户视觉未验证。

## 背景

用户验收 1.8.0 后提出四项微调：

1. 删除左窗关闭键。
2. 右窗关闭键同时关闭左右两窗。
3. 放大右窗右上角两个按键并提高对比度。
4. 左窗增大到与右窗同宽，窗口组中心对称，左窗排版微调。

1.8.0 的左窗为 570×900，右窗为 660×900；实际右窗受内容最小宽度限制为 679。若直接把左窗设为 660，右窗仍会比左窗宽 1 像素。1.8.1 将两窗基准统一为 680×900。

## 改动

### 关闭键

- `RunHistoryPatch.OpenPopup` 不再创建左窗 `✕`。
- `ContributionPanel.ShowRunReplay` 新增关闭回调参数。
- 右窗关闭键在 `sts_replay_window` 状态下调用 `RunHistoryPatch.CloseOpenPopup`，同时关闭左右两窗。
- 实时 F8 面板的关闭键仍只隐藏自身，不关闭历史弹窗。
- `ClearReplayWindow` 清空关闭回调，避免下一次实时模式误用历史回调。

### 右窗按键

- `?` 与 `✕` 从 32×32 改为 40×40。
- 字号从 14 改为 18。
- 帮助键使用深蓝底色与亮蓝边框；关闭键使用深红底色与亮红边框。
- 两键使用白色文字、黑色描边和 2 像素边框；悬停与按下状态使用更亮或更暗的底色。

### 双窗几何

- `ComputeWindowRects` 基准改为 `680×900 + 16 + 680×900`。
- 1920×1080 视口下，左窗 `(272,90)`，右窗 `(968,90)`，左右外边距均为 272。
- 总宽 1376，占视口 71.7%；高度 900，占视口 83.3%。

### 左窗排版

- 标题字号从 28 改为 30，标题行最小高度 42。
- 左右外边距从 16 改为 18。
- 分节内边距从 12 改为 16。
- 表格列距从 12 改为 16。
- 数值列最小宽度从 56 改为 64。
- 纵向间距不变，真实 49 层内容仍不出现滚动。

## 验证

### v0.113.1 游戏内布局探针

使用真实 49 层历史 `1795349355.run`，探针在无头游戏内调用 `RunHistoryPatch.OpenPopup`：

- 左右窗均 `680×900`。
- 左窗 `(272,90)`，右窗 `(968,90)`，间距 16。
- 左右外边距均 272，`sameWidth=True`，`symmetric=True`。
- 总宽比 0.717，高度比 0.833。
- 左窗无 `✕`，右窗 `?` 与 `✕` 存在。
- 两键最小尺寸 40×40，边框 2，字号 18。
- 左窗无重复「本局统计」标题，无「查看贡献图表」按钮。
- 左窗内容高度 799，滚动页高度 799，无纵向滚动。
- 点击右窗 `✕` 后，右窗隐藏，左窗节点同时移除。
- 空贡献汇总仍显示右窗空状态。
- 结果：`RESULT PASS`。
