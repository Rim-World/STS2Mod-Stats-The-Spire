## 3. 历史课证据

- 第 1 回合自动打出 `BLUDGEON`，记录为上一回合攻击牌。
- 第 1 回合获得 `HistoryCourse`。
- 第 2 回合 `AfterAutoPrePlayPhaseEntered` 真实触发。
- 探针输出 `HISTORY_HOOK ... turn=2 phase=AutoPrePlay inRelics=True`。
- 复制牌 `BLUDGEON` 被标记为 `dupe=True`。
- `HISTORY_COURSE` 行：`auto=1`、`direct=32`、`TimesPlayed=0`。
- 原 `BLUDGEON` 行仍为 `auto=1`，没有因复制牌增加。
- 失败经验：探针的 `AsyncLocal` 自动出牌门无法限制从战斗回合循环进入的遗物 hook；测试必须在结束回合期间关闭全局门。生产代码没有这个门。

## 4. 能力来源证据

- `HELLRAISER` 行：`auto=1`、`direct=6`、`TimesPlayed=0`；`STRIKE_IRONCLAD` 无自动子行；`HELLRAISER_POWER` 无独立行。
- `LOST_LUTE` 行：`auto=1`、`TimesPlayed=0`；自动打出的 `DEFEND_SILENT` 无自动子行。
- 探针中 `ContributionMap.GetPowerSource` 返回 `null`；因此实际验证的是 `ResolveAutoPlayRoot` 的 `HELLRAISER_POWER` / `LOST_LUTE_POWER` 回退映射，而不是真实施加来源表。真实来源存在时，现有优先级保持不变。
- 模仿学习没有单人运行证据；代码路径为：能力 hook 前缀建立上下文，`ResolveAutoPlayRoot` 回退到 `IMITATION_LEARNING`。

## 5. 现有路径证据

- 精炼混沌：药水行 `auto=3`，来源类型 `potion`。
- 注能：`DEFEND_SILENT` 被附魔后自动打出，卡牌行 `autoDelta=1`；没有 `IMBUED` 行。探针直接调用附魔 hook，不是战斗开始时自然触发。
- 彼岸咆哮：卡牌自身行 `autoDelta=1`、`direct=18`。探针直接调用 `AfterAutoPostPlayPhaseEntered`，不是回合结束自然触发。
- 愚者：`THE_FOOL` 行 `autoDelta=2`；被自动打出的 `DEFEND_SILENT` 没有增加自动行。
- 奇巧：不修改、不拆分、不测试。用户批准保留当前口径。
