# 1.8.1 双窗等宽与关闭键合并

- 计划编号：029-S
- 建立时间：2026-11-23 01:16
- 状态：已实现（v0.113.1 布局探针 PASS；双版本构建 0 错误；用户视觉未做）
- 适用 Mod：1.8.1
- 游戏基准：v0.113.1（提交 `d09d48e5`）；v0.111.1 用参考程序集构建

## 1. 目标

- 删除左侧统计窗口的关闭键。
- 右窗关闭键同时关闭左右两窗；Esc 与遮罩继续关闭全部。
- 右窗帮助键与关闭键放大到 40×40，使用高对比底色、亮色边框和白色文字。
- 左右窗改为同宽、同高、同顶边，窗口组在视口中心对称。
- 左窗加大到与右窗相同宽度；横向内边距、表格列距和数值列宽同步放大。
- 左窗仍然不显示重复标题，真实 49 层内容不出现纵向滚动。
- 不修改统计字段、JSON、历史数据、图表归因和实时 F8 面板布局。

## 2. 非目标

- 不改变右窗图表内容和归因。
- 不改变回放窗口固定位置与禁用拖动/缩放的规则。
- 不改变跑局历史按钮注入位置。
- 不增加新的窗口拖动、缩放或键盘焦点行为。

## 3. 设计

- `RunHistoryPatch.ComputeWindowRects` 改为 `680×900 + 16 + 680×900` 等宽基准，按视口缩放并居中。
- 左窗删除 `✕` 按钮；标题字号改为 30，标题行保留 42 像素高度。
- 左窗外边距改为左右各 18；统计分节内边距改为 16；表格列距 16，数值列最小宽度 64。
- `ContributionPanel.ShowRunReplay` 接收关闭回调；右窗关闭键在回放模式下调用 `RunHistoryPatch.CloseOpenPopup`，实时模式只隐藏自己。
- `ContributionPanel` 增加 `StyleHeaderButton`：40×40、18 号字、2 像素亮色边框、深蓝帮助键和深红关闭键、白色文字与深色描边。

## 4. 验收

- v0.113.1 游戏内布局探针：
  - 左右窗同宽、同高、同顶边，左右外边距相等。
  - 左窗无 `✕`，右窗有 `?` 与 `✕`。
  - 两键最小尺寸不小于 40，字号不小于 18，normal 样式边框不小于 2。
  - 点击右窗 `✕` 后左窗与右窗同时消失。
  - 左窗无重复「本局统计」标题，无「查看贡献图表」按钮，无纵向滚动。
  - 无汇总数据的旧局仍打开空右窗。
- v0.113.1 与 v0.111.1 Release 构建 0 错误。
- 发布门禁与安装加载检查通过。
- 用户实机视觉检查；未做时标明未验证。
