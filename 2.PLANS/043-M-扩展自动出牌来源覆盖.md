## 1. 目标

补齐自动出牌来源上下文。自动打出的牌产生的数值必须进入触发它的卡牌、遗物或能力的来源行。

本轮只处理已确认的缺口：

1. 历史课（`HISTORY_COURSE`）遗物。
2. 地狱狂徒（`HELLRAISER_POWER`）能力。
3. 模仿学习（`IMITATION_LEARNING_POWER`）能力。
4. 失落鲁特琴（`LOST_LUTE_POWER`）能力。

同时验证现有路径是否成立：

- 卡牌自身 `OnPlay` 中自动打出其他牌。
- 轰击、彼岸咆哮在阶段 hook 中自动打出自身。
- 注能被附魔的卡牌在战斗开始时自动打出自身。
- 精炼混沌药水从抽牌堆自动打出牌。

用户已明确批准：奇巧（`SLY`）不拆分手动打出与丢弃时自动打出。本轮不得为奇巧新增独立来源字段、界面行或测试门槛。

## 2. 现状

当前自动牌进入 `CombatTracker.OnCardPlayStarted` 后，按以下优先级解析根来源：

1. 活动能力来源。
2. 活动遗物来源。
3. 活动药水来源。
4. 当前活动卡牌。
5. 卡牌记录的生成来源。
6. 被自动打出的卡牌自身。

现有缺口的原因不是汇总逻辑，而是触发 hook 没有设置活动上下文。

| 来源 | 官方中文 | 触发 hook | 当前结果 | 本轮动作 |
|---|---|---|---|---|
| `HistoryCourse` | 历史课 | `AfterAutoPrePlayPhaseEntered` | 无遗物上下文；复制牌落到自身 | 补遗物上下文 |
| `HellraiserPower` | 地狱狂徒 | `AfterCardDrawnEarly` | 无能力上下文；抽到的攻击牌落到自身 | 补能力上下文 |
| `ImitationLearningPower` | 模仿学习 | `AfterCardPlayed` | 无能力上下文；克隆牌落到自身 | 补能力上下文；单人无自然触发 |
| `LostLutePower` | 失落鲁特琴 | `AfterCardPlayed` | 无能力上下文；抽牌堆的牌落到自身 | 补能力上下文；v0.111.1 无此类型 |
| `DistilledChaos` | 精炼混沌 | `OnUse` | 已有药水上下文 | 只做定向验证 |
| `Imbued` | 注能 | `AfterAutoPrePlayPhaseEntered` | 无附魔上下文；落到被附魔卡牌自身 | 不新增来源；验证现行口径 |
| `Bombardment` | 轰击 | 自动出牌前阶段 | 落到卡牌自身 | 不新增来源；验证现行口径 |
| `HowlFromBeyond` | 彼岸咆哮 | 自动出牌后阶段 | 落到卡牌自身 | 不新增来源；验证现行口径 |
| 12 张 `OnPlay` 卡牌 | 见 `051-T` 第 3 节 | `OnPlay` 内调用自动出牌 | 当前活动卡牌应覆盖 | 不新增来源；抽样验证 |
| `SLY` | 奇巧 | 丢弃后自动打出 | 按当前口径统计 | 明确跳过 |

## 3. 设计

### 3.1 历史课

在 `RelicHookContextPatcher.PatchAll` 增加：

```text
TryPatch(harmony, typeof(HistoryCourse),
    "AfterAutoPrePlayPhaseEntered", prefix, postfix);
```

- 使用现有 `CaptureAttributionContext`、`SetActiveRelic`、`RestoreAttributionContext`。
- 历史课只在玩家回合数不等于 1 时触发；测试必须进入第 2 回合。
- 自动打出的复制牌必须归到 `HISTORY_COURSE`，不得归到复制牌或上一张攻击牌。
- 类型或方法缺失时，`TryPatch` 记录警告并跳过。

### 3.2 三个能力

在 `PowerHookContextPatcher.PatchAll` 增加：

```text
HellraiserPower.AfterCardDrawnEarly
ImitationLearningPower.AfterCardPlayed
LostLutePower.AfterCardPlayed
```

`PowerHookContextPatcher` 已负责：

- 只为本地玩家的能力建立上下文。
- 优先使用 `ContributionMap.GetPowerSource` 的真实来源。
- 在能力来源缺失时保留 `_activePowerId`，供根来源回退映射使用。
- 在 hook 结束后恢复外层上下文。

`LostLutePower` 在 v0.111.1 不存在。`PowerHookContextPatcher` 必须新增运行时类型查找，不得直接写 `typeof(LostLutePower)`，否则 v0.111.1 构建或加载会失败。类型缺失时必须记录并跳过。

### 3.3 根来源回退映射

在 `CombatTracker.ResolveAutoPlayRoot` 的 `switch` 增加：

```text
"HELLRAISER_POWER" => ("HELLRAISER", "card")
"IMITATION_LEARNING_POWER" => ("IMITATION_LEARNING", "card")
"LOST_LUTE_POWER" => ("LOST_LUTE", "card")
```

规则：

- 只有在 `ContributionMap.GetPowerSource` 找不到真实来源时，才使用这些映射。
- 真实来源是卡牌、遗物或药水时，保留真实来源，不得覆盖。
- 没有真实来源且没有映射时，继续按当前逻辑回退，不得编造来源。

### 3.4 不做改动的路径

以下路径沿用现有逻辑：

- 12 张卡牌在自身 `OnPlay` 中自动出牌：当前活动卡牌是根来源。
- 轰击、彼岸咆哮：没有外层来源时，卡牌自身是根来源。
- 注能：被附魔卡牌自身是根来源；不新增“附魔”来源行。
- 精炼混沌：现有药水上下文是根来源。
- 奇巧：按用户批准，不区分手动打出与丢弃时自动打出。

## 5. 验证计划

### 5.1 构建

- 三个版本 Release 构建 0 错误。
- 单个 DLL 形态不变。
- v0.111.1 加载时记录失落鲁特琴类型缺失并继续启动。

### 5.2 定向探针

| 探针 | 真实触发 | 必须检查 |
|---|---|---|
| 历史课 | 第 1 回合打出攻击牌，结束回合，第 2 回合开始 | `HISTORY_COURSE` 行 `AutoPlayedCount` 增加；复制牌无子行；伤害进入遗物行 |
| 地狱狂徒 | 给本地玩家添加能力，再抽一张带打击标签的牌 | `HELLRAISER` 行增加自动次数与伤害；抽到的牌无自动子行 |
| 失落鲁特琴 | 给本地玩家添加能力，再打出旋律牌 | `LOST_LUTE` 行增加自动次数与数值；抽牌堆的牌无子行；v0.111.1 跳过 |
| 模仿学习 | 仅多人环境可自然触发 | 检查能力上下文与映射；单人运行标为未验证，不得伪造 PASS |
| 精炼混沌 | 使用药水 | 药水行增加自动次数；自动牌无子行；伤害与格挡进入药水行 |
| 注能 | 给技能牌附魔，进入战斗 | 被附魔卡牌行增加自动次数；没有独立附魔行 |
| 轰击或彼岸咆哮 | 将卡牌放入消耗堆并触发阶段 | 卡牌自身行增加自动次数；没有额外来源行 |
| `OnPlay` 卡牌 | 至少测试愚者与倾泻 | 来源卡行增加自动次数；自动牌无子行 |
| 奇巧回归 | 丢弃奇巧牌 | 现有口径不变；不新增手动/自动拆分字段 |

### 5.3 数据核对

- 根来源行的 `TimesPlayed` 不因自动出牌增加。
- 根来源行的 `AutoPlayedCount` 等于实际自动出牌次数。
- 自动牌不生成独立贡献行。
- 同一笔伤害、格挡、抽牌、能量或治疗只写入一次。
- 实际扣血、格挡和资源变化与探针记录一致。
- 保存、重载后字段保持。
- 旧 JSON 缺少字段时继续按 0 读取。

## 7. 风险

- 异步 hook 的 prefix/postfix 必须覆盖完整 `await` 链；探针必须使用真实 hook。
- 历史课在第 2 回合才触发；探针不能只检查第 1 回合。
- 失落鲁特琴在 v0.111.1 不存在；直接引用类型会导致版本兼容失败。
- 模仿学习需要另一名玩家；单人环境不能完成运行验收，必须如实标记未验证。
- 能力真实来源优先于回退映射；错误覆盖会把遗物或药水来源改成卡牌。
- 注能、轰击和彼岸咆哮的现行口径是“卡牌自身”；本轮不改变展示方式。
- 奇巧明确不做拆分；不得在实现中顺手新增来源行。
