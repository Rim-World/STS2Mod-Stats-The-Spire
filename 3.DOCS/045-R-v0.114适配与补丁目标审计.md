# v0.114.0 适配与补丁目标审计

- 编号：045-R

## 1. 适配结论

| 项目 | 结论 | 处理 |
|---|---|---|
| RitsuLib | 0.6.16 才提供 v0.114.0 运行时变体 | 编译改用 `STS2.RitsuLib.Compat.0.111.0` 0.6.16；manifest 最低版本升到 `0.6.16` |
| `Creature.LoseHpInternal` | 返回值改为 `HpLossResult`，增加 `dryRun` | 本项目不直接调用；`CombatHistory.DamageReceived` 仍接收 `DamageResult`，无需改接 |
| `DamageBlockInternal` | 增加 `dryRun` | 未直接调用；无需改接 |
| `CardModel.UpgradeInternal` | 增加 `bool silent` | 未直接调用；`CardCmd.Upgrade` 观察点仍存在 |
| `CardModel.DowngradeInternal` | 增加 `int downgradeAmount` | 未直接调用 |
| `FreeCardPower` | 删除 | 仅注释引用；无运行依赖 |
| `RapidShot` | 重做为 `TwinShot` | 无运行引用；不可新增编译期引用 |
| `HappyFlower` / `FakeHappyFlower` | 能量触发从 `AfterSideTurnStart` 移到 `AfterPlayerTurnStartEarly` | 用 `Safe.TryPatchFirst` 按声明方法选择 |
| `TunePower` | 从回合结束免费牌改为获得 Ki 旋律时升级手牌 | 0.113 绑 `AfterSideTurnEnd`，0.114 绑 `AfterCardPlayed` |
