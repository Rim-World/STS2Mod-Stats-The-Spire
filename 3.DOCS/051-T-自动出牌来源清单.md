# 自动出牌来源清单与缺口

- 编号：051-T
- 时间：2026-11-28 19:15
- 适用游戏：Slay the Spire 2 v0.114.0
- 结论：不是只有乱战、惊逃、傻瓜和低语耳环。游戏内还有多张卡牌、能力、遗物、附魔与药水会调用自动出牌。多数卡牌来源可由现有活动卡牌上下文覆盖；明确缺少独立来源上下文的是历史课、地狱狂徒、模仿学习和遗失鲁特琴。`Imbued` 与 Sly 的口径需要确认。

## 1. 搜索方法

搜索游戏反编译源码：

```text
5.STS2-114Reference/decompiled
```

匹配：

```text
CardCmd.AutoPlay(
CardPileCmd.AutoPlayFromDrawPile(
```

排除：

- AutoSlayer 测试机器人 `CombatRoomHandler`；
- `CardPileCmd` 自身的 helper 定义；
- 测试和开发控制台代码。

`AutoPlayFromDrawPile` 是 helper，实际来源由调用它的卡牌、能力、遗物或药水决定。

## 2. 已显式覆盖

| 来源 | 类型 | 触发 |
|---|---|---|
| `MayhemPower`（乱战） | 能力 | 自动出牌前阶段，从抽牌堆顶自动打出 |
| `StampedePower`（惊逃） | 能力 | 自动出牌后阶段，从手牌自动打出攻击牌 |
| `SimpletonPower`（傻瓜） | 能力 | 自动出牌后阶段，从手牌自动打出低费牌 |
| `WhisperingEarring`（低语耳环） | 遗物 | 第一回合自动出牌前，瓦库自动打出至多 13 张手牌 |

这些来源已设置根来源，自动牌行不单独建立。

## 3. 卡牌自身 OnPlay 的自动出牌

下列卡牌在 `OnPlay` 内调用 `CardCmd.AutoPlay` 或 `CardPileCmd.AutoPlayFromDrawPile`。它们执行时通常已有 `_activeCardId`，因此现有路径预计会把自动牌归到这张来源卡。

| 来源 | 行为 |
|---|---|
| `BeatDown` | 从弃牌堆自动打出攻击牌 |
| `Catastrophe` | 从抽牌堆自动打出牌 |
| `ChoChorus` | 自动打出手牌中的 Wah/Ki 牌 |
| `DecisionsDecisions` | 选一张技能牌并重复自动打出 |
| `Eidolon` | 自动打出消耗堆中的虚无牌 |
| `KnifeTrap` | 自动打出消耗堆中的小刀 |
| `TheFool` | 从手牌自动打出牌 |
| `Uproar` | 从抽牌堆自动打出攻击牌 |
| `Cascade` | 从抽牌堆顶自动打出牌 |
| `Havoc` | 从抽牌堆顶自动打出并消耗 |
| `IAmInvincible` | 从抽牌堆顶自动打出 |
| `TheDevil` | 从抽牌堆顶自动打出多张牌 |

状态：代码路径预计覆盖；未逐张做定向探针。

## 4. 卡牌阶段 hook 自动打出自身

| 来源 | 行为 |
|---|---|
| `Bombardment` | 在自动出牌前阶段，若在消耗堆则自动打出自身 |
| `HowlFromBeyond` | 在自动出牌后阶段，若在消耗堆则自动打出自身 |

这两张没有活动卡牌上下文时，`ResolveAutoPlayRoot` 会回退到被自动打出的卡牌自身，因此预计落到卡牌自己的 `AutoPlayedCount` 行。没有专门的来源映射；是否符合预期需定向确认。

## 5. 能力来源

| 来源 | 行为 | 当前状态 |
|---|---|---|
| `HellraiserPower` | 抽到攻击牌时自动打出该牌；无限 HP 场景最多 9 次 | 缺少 power 上下文 patch；自动牌预计落到攻击牌自身 |
| `ImitationLearningPower` | 复制对手的能力牌并自动打出克隆 | 缺少 power 上下文 patch；自动牌预计落到克隆牌 |
| `LostLutePower` | 每回合首次打出 Wah/Cho/Ki 牌时，从抽牌堆自动打出牌 | 缺少 power 上下文 patch；自动牌预计落到抽出的牌 |
| `MayhemPower`、`StampedePower`、`SimpletonPower` | 见第 2 节 | 已显式覆盖 |

## 6. 遗物、附魔与药水

| 来源 | 类型 | 行为 | 当前状态 |
|---|---|---|---|
| `HistoryCourse` | 遗物 | 上回合打出过攻击牌时，自动打出其复制 | 缺少 relic 上下文；自动牌预计落到复制牌自身 |
| `WhisperingEarring` | 遗物 | 第一回合自动打出至多 13 张手牌 | 1.12.0 已显式覆盖 |
| `Imbued` | 附魔 | 第一回合自动打出被附魔的技能牌 | 没有附魔来源上下文；会回退到被附魔卡牌自身，口径待确认 |
| `DistilledChaos` | 药水 | 从抽牌堆自动打出牌 | 使用药水上下文，预计覆盖 |

## 7. Sly 关键字

`CardCmd.DiscardAndDraw` 会对 Sly 牌调用 `CardCmd.AutoPlay(..., AutoPlayType.SlyDiscard)`，这是自动出牌机制，不是单独的模型来源。

- 弃牌由卡牌 `OnPlay` 触发时，`_activeCardId` 应覆盖。
- 弃牌由遗物、能力或药水触发时，是否存在对应来源上下文需要确认。

## 8. 完整缺口

明确需要补独立来源上下文：

1. 历史课 `HistoryCourse`：遗物 hook。
2. 地狱狂徒 `HellraiserPower`：能力 hook。
3. 模仿学习 `ImitationLearningPower`：能力 hook。
4. 遗失鲁特琴 `LostLutePower`：能力 hook。

口径待确认：

- `Imbued` 附魔：归被附魔卡牌，还是归施加附魔的来源。
- Sly 弃牌：非卡牌触发时归谁。
- `Bombardment`、`HowlFromBeyond`：自身行是否符合预期。
- 所有 OnPlay 卡牌的自动出牌：现有活动卡牌上下文是否在每一张牌上都实际成立，需要定向验证。

## 9. 结论

目前不能把自动出牌来源限定为乱战、惊逃、傻瓜和低语耳环。至少还有 4 个明确缺少独立来源上下文的来源；其余多数卡牌类来源预计由现有路径覆盖，但尚未全部逐项验证。
