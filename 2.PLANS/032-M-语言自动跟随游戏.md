# 自动跟随游戏语言

- 计划编号：032-M
- 建立时间：2026-11-23 02:44
- 状态：已实现（四种游戏语言探针通过；双版本构建；门禁 12/12；最终安装加载通过；图形界面视觉与 v0.111.1 运行未做）
- 拟目标版本：1.9.0
- 游戏基准：v0.113.1（提交 `d09d48e5`）；v0.111.1 用参考程序集构建
- 来源：用户 2026-11-23 指令；`1.PRD/用户prompt/0052.md`、`1.PRD/用户prompt/0053.md`、`1.PRD/用户prompt/0054.md`

## 1. 目标

- 游戏语言为简体中文或繁体中文时，Mod 界面使用中文。
- 简体中文与繁体中文都使用现有简体中文界面字典；繁体游戏接受「简体 Mod 文案 + 繁体游戏名称」的混用。
- 游戏语言为中文时，卡牌、遗物、药水、事件、怪物、先古等名称使用游戏当前中文表。
- 游戏语言不是中文时，Mod 自己的按钮、标题、说明、统计标签使用英文。
- 游戏语言不是中文时，名称使用游戏当前语言表，不优先使用英文名表。
- 游戏语言为英文时，名称使用英文表。
- 删除 RitsuLib 设置页中的语言设置项。
- 删除 `mod_prefs.json` 的 `language` 读取与保存路径；旧值保留在磁盘时忽略。
- 语言改动后重启游戏即可完成全量刷新；不实现同一进程内的热切换。

## 2. 非目标

- 不增加中文、英文之外的 Mod 界面语言。
- 不增加繁体中文界面字典，不在运行时做简繁转换。
- 不翻译游戏原始内容。
- 不改变统计字段、归因规则、JSON 格式、历史数据、图表数据或战斗计算。
- 不保留“Mod 语言独立于游戏语言”的覆盖能力。
- 不修改游戏原生的 Options → Language 设置。
- 不实现运行中语言热切换、语言事件订阅或语言缓存失效。
- 不自动迁移用户已有的 `language` 配置值。

## 3. 现状与证据

- `ModConfig.Language` 默认 `CN`，从 `mod_prefs.json` 读取，保存时写回。证据：`9.SRC/src/Config/ModConfig.cs:16`、`:114`、`:180`。
- 启动时把 `ModConfig.Language` 写入 `L.Current`。证据：`9.SRC/src/CommunityStatsMod.cs:27`、`:30`。
- RitsuLib 设置页提供 `中文` / `English` 下拉项。证据：`9.SRC/src/Settings/RitsuSettingsPage.cs:40`。
- `L.Get` 只读取 `L.Current`，不读取游戏语言。证据：`9.SRC/src/Config/Localization.cs:49`。
- `L.GetByGame` 会读取 `TranslationServer.GetLocale()`，但全仓库没有调用点。
- `NameLookup` 在 Mod 为英文时优先使用内置英文名表，即使游戏当前不是英文。证据：`9.SRC/src/Util/NameLookup.cs:125`、`:132`。
- `NameLookup` 在 Mod 为中文时使用游戏 `LocManager` 当前表。证据：`9.SRC/src/Util/NameLookup.cs:11`、`:53`。
- `MonsterIntentMetadata` 在烘焙时缓存 `DisplayName`。重启游戏会重新烘焙；本计划不处理同一进程内的旧缓存。
- 现有 SPEC 要求保留 `language` 设置。新需求与 `SP-017`、`SP-019` 冲突。证据：`6.SPEC/001-总体规范.md:47`、`:53`。

## 4. 设计

### 4.1 语言判定

- `L.Current` 改为由游戏语言推导，不再由用户配置赋值。
- 首选 `LocManager.Instance.Language`，取值为 `zhs` 或 `zht` 时返回中文，否则返回英文。
- `LocManager.Instance` 尚未初始化时，回退到 `TranslationServer.GetLocale()`；语言代码以 `zh` 开头时返回中文。
- 中文界面统一使用现有 `CN` 字典；`zht` 不新增字典，也不做简繁转换。
- 保留 `L.Lang` 枚举的 `CN` / `EN` 两个值。
- 游戏原生 Options → Language 保留；删除的是 Mod 在 RitsuLib 设置页里的语言项。

### 4.2 设置项删除

- 删除 `ModConfig.Language` 属性。
- 删除 `LoadOverrides` 对 `language` 的读取。
- 删除 `SaveSettings` 对 `language` 的写入。
- 删除 RitsuLib 设置页的 `language` 下拉项。
- 删除 `settings.language` 键及设置页描述中的语言字样。
- 删除 `CommunityStatsMod` 启动时的 `L.Current` 赋值。
- 旧 `mod_prefs.json` 的 `language` 键不读取；下一次保存设置时自然消失。
- 删除只服务手动语言切换的 `L.LanguageChanged` 事件与订阅，避免留下死路径；若其他界面刷新仍需要该事件，保留事件但不再由设置页触发。

### 4.3 名称解析

- `NameLookup` 改为始终使用游戏当前语言表。
- 删除“Mod 为英文时优先内置英文表”的分支。
- 删除内置英文名表与英文 `_fallback` 优先路径；官方支持语言的词表完整，正常路径不依赖英文兜底。
- 当前语言表查不到名称时，防御性返回原始 ID；不显示空字符串。
- `IntentStateMachinePanel` 不再根据 `L.Current == EN` 选择名称来源；统一使用游戏当前语言。
- 意图状态机示意图的标签仍只有中文与英文两套；名称来自游戏当前语言表。
- 审计直接读取 `Title.GetFormattedText()` 的路径，确保它们与 `NameLookup` 使用同一套语言。
- 保留 `FoolMelodyReplacer` 的占位符与 BBCode 清理逻辑。

### 4.4 语言刷新

- 不订阅 `LocManager` 的语言变化事件。
- 语言改动后重启游戏；重启后所有面板重新创建，名称与标签使用新语言。
- 同一进程内不保证已打开面板换字；新打开的面板可能读取新词表，但完整一致必须重启。
- 该限制写入 README 与 Mod 设置页说明：语言自动跟随游戏；更改游戏语言后请重启游戏。
- `MonsterIntentMetadata` 的 `DisplayName` 缓存不额外失效；重启会重新烘焙。
- 其他独立面板在下一次打开时读取当前语言。

### 4.5 文档与规范

- 新增 PRD 需求，记录自动跟随规则与删除语言设置项。
- 废止或改写 `SP-017`、`SP-019`，新增自动语言条款。
- 更新 SDD 的界面层语言路径与刷新范围。
- 更新 README 的语言说明，删除“可手动选择中文/英文”的表述，写明「语言跟随游戏；更改游戏语言后重启游戏」。
- 在 Mod 设置页说明中写明「语言自动跟随游戏；更改游戏语言后重启游戏」。
- 更新设置页语言键与描述，删除手动语言选项。
- 目标版本按 1.9.0 规划；最终版本号在批准后确认。

## 5. 已确认边界

- 繁体中文游戏使用简体字典；接受简繁混用。
- 名称只使用游戏当前语言表；官方词表完整，不保留英文优先或英文兜底。
- 不再读取旧设置中的 `language`。
- 意图状态机界面仍只有中文与英文两套标签；名称随游戏语言。
- 语言改动不是高频操作；重启游戏可以完成刷新。
- 不实现运行中语言热切换。
- 删除 Mod 设置页语言项，不删除游戏原生语言设置。

## 6. 验收

- 游戏为 `zhs`：Mod 界面简体中文，名称为游戏简体中文。
- 游戏为 `zht`：Mod 界面简体中文，名称为游戏繁体中文。
- 游戏为 `eng`：Mod 界面英文，名称为英文。
- 游戏为 `jpn` 或其他非中文语言：Mod 界面英文，名称为游戏当前语言，不出现英文名表优先。
- 设置页不再出现语言选项；`ModConfig.Language` 与 `settings.language` 不再存在。
- 旧 `mod_prefs.json` 的 `language` 值不改变界面；下一次保存后该键消失。
- README 与 Mod 设置页说明写明：语言跟随游戏；更改游戏语言后重启游戏。
- 语言改动后重启游戏，贡献面板、意图名称与其他面板全部使用新语言。
