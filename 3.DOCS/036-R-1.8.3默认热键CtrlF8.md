# 1.8.3 默认热键改为 Ctrl+F8

- 报告编号：036-R
- 时间：2026-11-23 02:21
- 适用版本：Mod 1.8.3
- 游戏基准：v0.113.1；v0.111.1 仅程序集构建
- 结论：默认热键与非法回退已改为 `Ctrl+F8`；v0.113.1 启动注册成功；本地配置只改热键，其他设置保持。用户物理 `Ctrl+F8` 未验证。

## 1. 原因

原默认值 `F8` 与当前安装中的 `Rewind` 模组重叠。日志：

```text
[sts2.piyixiajiuhenfen.rewind] Rewind v0.26.21 initialized! F4=Rewind, F8=CopySeed, F9=Checkpoint, Reroll=None
[RuntimeHotkey] Registered 'F8' for StatsTheSpire.ContributionPanel
```

RitsuLib 不会替所有模组强制分配唯一键。改为 `Ctrl+F8` 可以保留功能键的操作习惯，同时降低普通 F8 的冲突概率。

## 2. 改动

- `9.SRC/src/Config/ModConfig.cs`：默认值改为 `"Ctrl+F8"`。
- `9.SRC/src/Settings/HotkeyRegistration.cs`：默认绑定与非法回退改为 `"Ctrl+F8"`。
- `9.SRC/src/Config/Localization.cs`：设置说明、面板帮助和帮助行改为 `Ctrl+F8`。
- `9.SRC/README_ZH.md`、`README_EN.md`、`README.md`：当前默认值说明改为 `Ctrl+F8`。
- 既有用户配置不自动迁移；只有用户明确要求时才改本地值。
- 本机 `%AppData%/sts2_community_stats/mod_prefs.json` 只替换 `contribution_panel_hotkey`。
- 未改变热键重绑定、持久化、文本输入/控制台抑制、双窗保护、统计字段和历史数据。

## 3. 本地配置

备份：`TMP/1.8.3/mod_prefs.before-1.8.3.json`

变更只有一行：

```diff
-  "contribution_panel_hotkey": "F8"
+  "contribution_panel_hotkey": "Ctrl+F8"
```

其他设置保持原值，包括：

- `language`: `CN`
- `feature_toggles.contribution_panel`: `false`
- 其他 7 个功能开关
- `use_my_data_only`: `false`
- `intent_panel_scale`: `0.8`

注：`contribution_panel=false` 只影响战斗结束自动弹出；热键打开路径不读取该开关。
