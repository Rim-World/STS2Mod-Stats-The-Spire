# 历史入口按钮宽度收窄

- 文档编号：040-R
- 日期：2026-11-25 03:56
- 版本：1.9.2
- 相关需求：RQ-029 / AC-030
- 结论：v0.111.1 无头按钮探针 PASS；双版本 Release 构建 0 错误；安装与最终加载通过。用户图形界面视觉未验证。

## 背景

1.9.1 将跑局历史「本局统计」入口按钮放大到 `390×75`、字号 `33`。用户实机查看后反馈左右空白过多。1.9.2 保留高度 `75`、字号 `33` 和位置 `(30, 210)`，将宽度从 `390` 收窄到 `350`。

## 改动

- `RunHistoryPatch.EntryButtonWidth` 从 `390f` 改为 `350f`。
- `CreateEntryButton()` 的 `CustomMinimumSize` 与左右偏移同步为 `350`。
- 按钮高度、字号、文本、图标、点击行为和双窗布局不变。
