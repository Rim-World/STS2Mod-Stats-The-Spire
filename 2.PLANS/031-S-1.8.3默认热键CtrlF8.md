# 1.8.3 默认热键改为 Ctrl+F8

- 计划编号：031-S
- 建立时间：2026-11-23 02:21
- 状态：已实现（Ctrl+F8 注册通过；双版本构建；本地设置已更新；用户物理 Ctrl+F8 未验证）
- 适用 Mod：1.8.3
- 游戏基准：v0.113.1（提交 `d09d48e5`）；v0.111.1 用参考程序集构建
- 来源：用户 2026-11-23 批准；`1.PRD/用户prompt/0051.md`

## 1. 目标

- 新安装或设置缺失时，贡献面板默认热键改为 `Ctrl+F8`。
- 非法绑定回退值改为 `Ctrl+F8`。
- 当前界面帮助、设置说明和 README 的默认值说明改为 `Ctrl+F8`。
- 用户本地 `%AppData%/sts2_community_stats/mod_prefs.json` 的 `contribution_panel_hotkey` 改为 `Ctrl+F8`；其他设置保持不变。
- 双窗回放期间忽略热键的 1.8.2 行为继续有效。
- F8 的单键绑定不再由本 Mod 默认注册。

## 2. 非目标

- 不自动迁移所有既有用户的 `F8` 设置；只有用户明确要求时才改本地值。
- 不改变热键重绑定、持久化、文本输入抑制或控制台抑制。
- 不改变双窗几何、统计字段、JSON、历史数据或图表归因。
- 不为其他 Mod 修改 F8 绑定。

## 3. 设计

- `ModConfig.ContributionPanelHotkey` 默认值改为 `"Ctrl+F8"`。
- `HotkeyRegistration.DefaultBinding` 改为 `"Ctrl+F8"`；非法配置回退到该值。
- `Localization` 的设置说明、帮助正文与帮助行改为 `Ctrl+F8`。
- README_ZH、README_EN、README 的当前默认值说明同步。
- 用户本地配置文件只替换 `contribution_panel_hotkey`；`feature_toggles`、语言、缩放等保持不变。
