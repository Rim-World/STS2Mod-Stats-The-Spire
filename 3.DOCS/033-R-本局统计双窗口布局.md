# 本局统计双窗口布局调整

- 报告编号：033-R
- 时间：2026-11-23 00:56
- 对应需求：RQ-025
- 对应计划：`2.PLANS/028-S-本局统计双窗口与信息密度调整.md`
- 对应版本：1.8.0

## 结论

跑局历史的「本局统计」现在一次打开两个窗口。左窗显示单局统计，右窗显示贡献图表；`查看贡献图表` 按钮已删除。1920×1080 下两窗总宽 65.9%、高 83.3%，左窗真实 49 层内容无需纵向滚动。

## 布局

| 项目 | 数值 |
|---|---|
| 左窗位置 | `(337, 90)` |
| 左窗尺寸 | `570×900` |
| 右窗位置 | `(923, 90)` |
| 右窗尺寸 | `679×900` |
| 间距 | `16` |
| 总宽 / 视口宽 | `65.9%` |
| 高 / 视口高 | `83.3%` |

右窗名义宽度为 660。实际宽度 679，来自 `ContributionPanel` 内容的最小宽度。两窗顶边和底边齐平。

## 实现

- `9.SRC/src/Patches/RunHistoryPatch.cs`
  - 计算左右矩形并居中。
  - 点击「本局统计」时同时创建左窗和右窗。
  - `CloseOpenPopup` 关闭左窗时隐藏右窗。
- `9.SRC/src/UI/RunHistoryStatsSection.cs`
  - 删除「查看贡献图表」按钮。
  - 删除内层重复标题。
  - 字号从 24/22 调整为 22/20；分区间距 10→6，面板内边距 14/10→12/8，行间距 3→2。
- `9.SRC/src/UI/ContributionPanel.cs`
  - `ShowRunReplay(summary, turns, position, size)` 设置固定左上锚点、位置和尺寸。
  - 回放期间设置 `sts_replay_window` 元数据并隐藏右下缩放手柄。
  - 关闭回放时恢复实时锚点、保存尺寸和保存位置。
  - 无贡献汇总时显示 `contrib.empty_run`。
- `9.SRC/src/UI/DraggablePanel.cs`、`ResizablePanel.cs`
  - 忽略带 `sts_replay_window` 元数据的面板，避免回放布局写入实时面板配置。
