## 4. 发现与修复

### 4.1 问题

首次 v0.111.1 胜利局没有生成 `summary.json`。同时 `live.json` 与 `shop_offers.json` 未删除。

原因：v0.111.1 的 `ModManager.OnMetricsUpload` 未触发。代码原先只在 `CreateRunHistoryEntry` 的 Postfix 中处理放弃结局，因此胜利和失败结局没有进入统一收尾。

### 4.2 修复

`RunLifecyclePatch.AfterCreateRunHistoryEntry`（`RunHistoryUtilities.CreateRunHistoryEntry` 的 Postfix）对所有结局调用 `RunDataCollector.OnMetricsUpload`。

`RunDataCollector` 新增 `_finalizedRunKey`：

- `BeginNewRun` 时清空。
- 首次收尾后写入 `identity.RunKey`。
- 同一 `RunKey` 再次收尾时直接返回。

修复后，v0.111.1 的放弃与胜利结局均生成摘要并清理运行态文件。v0.113.1 的 Postfix 先完成收尾，随后到达的事件路径由 `_finalizedRunKey` 拦截。
