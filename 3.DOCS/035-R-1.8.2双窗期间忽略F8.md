# 1.8.2 双窗期间忽略 F8

- 报告编号：035-R
- 时间：2026-11-23 01:53
- 适用版本：Mod 1.8.2
- 游戏基准：v0.113.1；v0.111.1 仅程序集构建
- 结论：双窗回放期间的热键路径已改为无操作；v0.113.1 探针 PASS。用户物理 F8 未验证。

## 1. 问题

1.8.1 的双窗关闭键会同时关闭左右两窗。贡献面板热键仍调用 `ContributionPanel.Toggle()`：

- 右窗可见时，热键走 `Hide()`，隐藏右窗并清除回放元数据。
- 左窗由 `RunHistoryPatch` 持有，不会随该路径关闭，因此会留下单窗。
- 再次按热键时，右窗以实时面板形态重新打开，覆盖在历史界面上。

这是 1.8.1 遗留的输入边界，不是关闭键回调的问题。

## 2. 改动

- `9.SRC/src/UI/ContributionPanel.cs:544` 的 `Toggle()` 在读取可见性前检查 `ReplayWindowMeta`。
- 元数据存在时直接返回；不调用 `Hide()`、`ClearReplayWindow()`、`RefreshTabs()` 或 `UpdateDps()`。
- 双窗关闭后元数据清除，F8 恢复实时面板开关。
- 右窗关闭键、Esc、遮罩与 `RunHistoryPatch.CloseOpenPopup()` 未改。
- 未改统计字段、JSON、历史数据、图表归因、双窗几何和热键绑定。
