# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ①设计目的

原项目：https://steamcommunity.com/sharedfiles/filedetails/?id=3748814804

原项目源码：[reddots1453/STS2mod-Stats_the_Spire](https://github.com/reddots1453/STS2mod-Stats_the_Spire)

原项目自8月以来没有再更新，github仓库从5月就停止了维护。制作本mod的目标有三个：

一是将原mod适配新版本的api；

二是修正其许愿式vibecoding产生的大量不合理设计与错误；

三是补充适配新版本的角色与游戏内容。

本 mod 支持 default 0.111.1 与 public beta 0.113.1。

## ②主要功能

本 mod 在游戏内外提供了丰富的统计内容。

在战斗内，展示各种稀有度的卡牌掉率、未知事件的分布概率、药水掉落概率等数据以辅助决策；

在历史记录中，展现各种卡牌、遗物、药水、事件、怪物的各项buff/debuff/伤害/回复等统计数据。

## ③其它功能与细节

你可以在Ritsulib设置页中对mod进行设置。

在对局中，你可以通过热键呼出战斗贡献菜单，默认快捷键是Ctrl + F8。你可以自定义热键。

## ④ 文件管理与隐私问题

游戏自带存档的记录是非常粗略的，它不记录战斗细节，只记录生命值变化、掉落哪些卡牌和资源等简略信息。

游戏过程中的细节信息——比如哪张牌提供了多少防御、哪张牌造成了多少伤害、某个遗物提供了哪些加成——只短暂保存在内存（RAM）之中，在战斗结束后就会消失。所以本mod必须读取游戏运行时对象中的变量，才能做到详细的统计。此外，本mod还有自己的配置存储文件mod_prefs.json。

所有本mod产生的文件位于C:\Users\username\AppData\Roaming\sts2_community_stats下，以明文方式保存游戏过程数据。文件默认最多保存90天，每次启动游戏并初始化mod时，mod会清除90天之前的详细数据。这一功能默认开启，你也可以选择在Ritsulib设置页将其关闭。这一设计是为了防止数据文件无限膨胀，在该功能开启时，通常本mod产生的数据少于30MB。

*90天是从对局文件最后一次增删或被替换时开始计算的，你可以近似认为是对局结束时。

*如果一个对局被暂停超过90天仍在进行中，它的详细数据不会被删除。

本 mod 不影响存档文件，也不存在任何遥测或联网行为。在启用mod时，历史记录最左侧会出现一个统计按钮。

## ⑤ 语言、环境与版本

本mod的语言支持分为两方面：mod ui的语言和游戏词表。

本mod的ui语言仅支持中文和英文。简体中文和繁体中文会显示简体中文，其余语言显示英文。

本mod的游戏词表直接使用游戏语言。各种卡牌、遗物、事件、药水等游戏术语，会跟随游戏语言。

举例说明：如果你是日语用户，你看到的mod ui语言是英语，但各项游戏术语会显示为日语。

本 mod 依赖基础 mod：RitsuLib。

本 mod 支持 default 0.111.1 与 beta 0.113.1 。在 0.111.1 中，新角色「愚者」及其他beta113版本的内容将不会出现。

## ⑥ 实现方式与兼容性

本 mod 的主逻辑基于原mod项目提供，未作迁移。RitsuLib 仅提供设置页相关功能与运行时热键注册。

本mod需要读取游戏运行时对象中的变量，原因见④。

兼容问题：联机兼容性未经仔细测试。

潜在Bug：对于192个harmony补丁的361个统计项，无法做到一一详尽测试，统计数据可能存在误差。

由于本mod包含太多统计项，可能跨版本兼容性较差，会出现统计错误。

本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。

## ⑦ 在原项目上的改动

原项目从时间和源码仓库中mods/sts2_statsthespire_local/DesignDoc/WORKFLOW.md文件推断，应该是使用 opus 4.7 + gpt 5.5 进行的编程。AI在架构设计上毫无常识，犯了较多的严重错误。

修改内容非常多，此处只概述主要的：

（1）删除了mod独立的语言设置选项。mod应当跟随游戏语言。

（2）修改了存储对局数据的主键，从随机种子改为时间戳。这是游戏的官方逻辑，因为同一个随机种子可能被复盘游玩多次。

（3）修改了原本的UI设计，使排版和色彩搭配更加合理，并将设置页面迁移到RitsuLib。

（4）对于一些明显错误的统计项目进行了修正，比如缩放仪、锁镰等。

（5）修正了高进阶时各稀有度卡牌的掉落概率与药水掉率的错误公式。

（6）修正了宠物吸收伤害的错误计算方式，增加了新的抽象，使其同时适用于奥斯提(Osty)和瓦皮（Wuppy）。

（7）修正了一些游戏术语的中文翻译错误，将其替换为官方翻译。

（8）修正了错误的数据计算方法，现在对伤害和价格的计算结果是向下取整而非四舍五入，与游戏事实相匹配。
