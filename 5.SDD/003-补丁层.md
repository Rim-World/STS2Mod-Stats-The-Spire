# 补丁层

- 版本：1.4.0
- 更新时间：2026-11-19 06:55
- 关联组件：`src/Patches/`、`src/Util/SafePatching.cs`

## 组件职责

补丁层把游戏事件转换为采集调用。它只负责“何时调用哪个采集方法”，不负责统计规则和 UI。

| 补丁组 | 代表符号 | 触发 |
|---|---|---|
| 运行生命周期 | `RunLifecyclePatch` | 新建/继续单人、多人游戏 |
| 战斗生命周期 | `CombatLifecyclePatch` | 战斗开始、回合、结束 |
| 战斗历史 | `CombatHistoryPatch` | 伤害、格挡、能力、遗物、药水事件 |
| 卡牌 | `CardLibraryPatch`、`CardRewardScreenPatch`、`CardUpgradePatch` | 卡牌奖励、升级、移除 |
| 遗物 | `RelicLibraryPatch`、`RelicHookContextPatcher` | 遗物触发与上下文 |
| 能力 | `PowerHookContextPatcher` | 能力施加与触发 |
| 地图与商店 | `MapPointPatch`、`ShopPatch` | 地图节点、商店库存与价格 |
| 意图 | `IntentHoverPatch`、`EnemyDamageIntentPatch` | 悬停、意图伤害 |
| 统计页 | `StatsScreenTabPatch`、`RunHistoryPatch` | 百科大全与历史页 |
| 兼容补丁 | `FiddleDrawCompatPatch`、`PaleBlueDotDrawCompatPatch`、`VoidFormEnergyCostPatch` | 新卡牌/能力的归因 |

## 依赖

允许：

- `Patches -> Collection`：调用采集方法。
- `Patches -> Config/Util`：读取设置、异常隔离、名称映射。
- `Patches -> Godot`：读取节点状态，但不得构造完整面板。

禁止：

- `Patches` 不得直接实现统计聚合。
- `Patches` 不得写文件；持久化由 `Collection`/`Util` 负责。
- `Patches` 不得在补丁方法中阻塞等待；异步操作必须交给后台任务。

静态检查：

```bash
rg -n "File\.|Directory\." 9.SRC/src/Patches
rg -n "Thread\.Sleep|\.Wait\(|\.Result" 9.SRC/src/Patches
```

## 补丁注册

`CommunityStatsMod.Initialize` 遍历程序集类型，对每个类型调用 `Harmony.CreateClassProcessor(...).Patch()`，单个类型失败只记录警告。之后调用手工补丁：

- `RelicHookContextPatcher.PatchAll`
- `PowerHookContextPatcher.PatchAll`
- `OrbPassivePatch.PatchOrbTurnEndTriggers`
- `OrbEvokePatch.PatchOrbEvokeMethods`
- `KillingBlowPatcher.PatchAll`
- `CardGenerationOriginPatch.Patch`
- `RunLifecyclePatch.RegisterMetricsHook`

对局结束时，`RunLifecyclePatch.CreateRunHistoryEntry` 的 Postfix 对胜利、失败与放弃结局统一调用 `RunDataCollector.OnMetricsUpload`。`RunDataCollector` 用 `RunKey` 记录已收尾对局；重复调用直接返回。v0.111.1 仍由该 Postfix 完成收尾；v0.113.1 若事件路径先完成收尾，Postfix 被去重。

## 目标探测

- 属性补丁使用 `[HarmonyPatch(typeof(X), nameof(X.Y))]`，编译期检查符号。
- 方法名可能随游戏版本变化时，使用 `AccessTools.DeclaredMethod` 或 `AccessTools.TypeByName` 探测。
- `TryPatch` 在目标缺失时记录 `[StatsTheSpire]` 警告并返回，不抛出。
- `Safe.TryPatchFirst` 依次尝试多个方法名，用于游戏版本改名（如 `JugglingPower`、`Pendulum`、`ToastyMittens`）。
- `HarmonyPrepare` 对可选补丁返回 `TargetMethod() != null`。

## 失败隔离

- 每个补丁入口包裹 `Safe.Run`。
- `Safe.RunAsync` 捕获异步异常。
- `Safe` 使用游戏 `Log.Warn`，不写独立日志文件。
- 单个补丁失败不得影响其他补丁注册。
