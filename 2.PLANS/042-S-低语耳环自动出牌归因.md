## 1. 目标

让先古遗物「低语耳环」（`WHISPERING_EARRING`）在第一回合自动打出的牌，按照现有自动出牌口径归到遗物根来源。

- 所有自动牌的伤害、修正伤害、升级伤害、格挡、修正格挡、减伤、自伤、宠物数值、抽牌、能量、星星与治疗写入 `WHISPERING_EARRING` 行。
- 每张自动牌只增加低语耳环行的 `AutoPlayedCount`，不建立自动牌自己的行。
- `TimesPlayed` 只统计玩家手动出牌；该遗物自动链不增加手动次数。
- 低语耳环每回合 +1 能量保持现有 `ModifyMaxEnergy` 归因，不与自动牌行重复。
- 嵌套自动牌继续归根来源；自动链内嵌手动牌保持独立。

## 2. 当前问题

低语耳环在 `WhisperingEarring.AfterAutoPrePlayPhaseEnteredLate` 中最多自动打出 13 张手牌。该 hook 当前未被 `RelicHookContextPatcher` 覆盖。

因此 `CardCmd.AutoPlay` 调用进入 `OnCardPlayStarted` 时没有 `_activeRelicId`，`ResolveAutoPlayRoot` 会走后备路径，把每张自动牌自己当作根来源，或落到卡牌来源。旧审计 C7-6、C10-6 已记录此问题。

## 3. 施工步骤

1. 在 `RelicHookContextPatcher.PatchAll` 为 `WhisperingEarring.AfterAutoPrePlayPhaseEnteredLate` 安装 prefix/postfix。
2. 使用现有 `CaptureAttributionContext` / `SetActiveRelic` / `RestoreAttributionContext`，不新增第二套上下文。
3. 保持 `TryPatch` 的运行时可选行为；类型或方法缺失时记录并跳过，不阻断启动。
4. 新增 `EarringProbe`：
   - 首场战斗进入 Play 阶段后添加低语耳环，避免自然 hook 与探针重复触发。
   - 清空手牌，加入 `BLUDGEON` 与 `DEFEND_SILENT`。
   - 通过真实 `AfterAutoPrePlayPhaseEnteredLate` 自动打出两张牌。
   - 暂停其它 `CardCmd.AutoPlay`，避免污染。
   - 检查低语耳环行 `AutoPlayedCount`、伤害、格挡；检查自动牌无行；检查遗物类型与来源。
5. v0.114.0 运行探针；v0.111.1 与 v0.114.0 Release 构建 0 错误；v0.113.1 为历史记录。
6. 构建 1.12.0 包并安装到游戏 `mods`；移除测试探针。

## 4. 验收

- `EarringProbe` 输出 `RESULT PASS`。
- 低语耳环行：`AutoPlayedCount` 等于实际自动牌数；`TimesPlayed` 为 0 或未写入；伤害与格挡非零；类型为 `relic`。
- `BLUDGEON`、`DEFEND_SILENT` 不产生自动行。
- 低语耳环 +1 能量仍只记一次。
- 三版本 Release 构建 0 错误；v0.114.0 加载一次主 Mod 初始化，设置页与 `Ctrl+F8` 正常。

## 5. 风险

- 异步 hook 的 prefix/postfix 必须覆盖完整 `await` 链；探针必须使用真实 hook，不能只手工调用 `OnCardPlayStarted`。
- 自然 hook 与探针手动调用可能重复触发；探针在 Play 阶段添加遗物，避开自然首回合 hook。
- 遗物 +1 能量与自动出牌行共用来源 ID；探针只验证不重复，不改变现有能量字段。
