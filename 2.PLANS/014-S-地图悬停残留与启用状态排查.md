# 地图悬停残留与启用状态排查

- 创建时间：2026-11-21 03:50
- 状态：部分完成（代码与无头探针完成；实际界面视觉验收与卡牌残影 A/B 未做）
- 关联需求：RQ-004、RQ-015
- 关联用户反馈：`1.PRD/用户prompt/0018.md`

## 现象

1. 本地 Mod 未勾选时，游戏仍出现 Stats the Spire 功能。
2. 勾选并重启后，地图上残留商店价格与未知房间概率悬停卡片。
3. 战斗出牌后，偶尔出现卡牌残影；来源未确认。

## 排查结论

### 1. 未勾选仍生效

- 游戏 `mods` 目录有本地版 `StatsTheSpire_Local_1.5.1_RQ014`。
- 创意工坊目录同时有原版 `3748814804/stats_the_spire_local`，版本 `1.3`，ID 同为 `sts2_statsthespire_local`。
- `settings.save` 中同 ID 有两条启用记录：`mods_directory` 与 `steam_workshop`。
- 当前日志实际加载本地版路径；同一日志另有同 ID 的跳过记录。
- 结论：两个副本共用 ID。勾选/取消勾选只影响其中一个条目时，另一个副本仍可加载。

### 2. 地图悬停卡片残留

- `MapPointPatch` 把 `InfoModPanel` 直接挂到 `NMapPoint` 下。
- 只在 `OnUnfocus` 时删除面板。
- `NMapScreen.Close` 只隐藏地图，不保证对每个地图点触发 `OnUnfocus`。
- 地图点节点在关闭后保留，旧面板随之保留；再次打开地图时仍然可见。
- 结论：关闭地图、清理地图、切换地图时必须主动删除全部悬停面板。

### 3. 卡牌残影

- 当前源码没有创建、复制或重挂卡牌视觉节点。
- 未发现本 Mod 在出牌流程中操作卡牌贴图、材质或卡牌节点生命周期。
- 当前日志没有本 Mod 的卡牌视觉异常。
- 结论：未确认与本 Mod 有关。

## 修复范围

1. `MapPointPatch` 增加统一面板登记表和 `HideAllHoverPanels()`。
2. 在 `NMapScreen.Close`、`CleanUp`、`Open`、`SetMap` 时机清理残留面板。
3. 删除面板时同时移除 `NMapPoint` 的元数据。
4. 修复 `CombatUiOverlayPatch.PinToLeftOfMap` 对非子节点调用 `MoveChild` 的错误。
5. 不改卡牌视觉代码；卡牌残影另做 A/B 验证。
