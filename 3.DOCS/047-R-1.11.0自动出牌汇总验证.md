# 1.11.0 自动出牌汇总验证

- 编号：047-R
- 时间：2026-11-28 00:20
- 适用版本：Mod 1.11.0；游戏 v0.114.0（运行）、v0.113.1 与 v0.111.1（构建）
- 需求：RQ-033、AC-032
- 结论：自动出牌按根来源汇总已实现。v0.114.0 定向探针 5/5 通过；根来源行、自动次数、实际伤害、无自动牌子行、无能力行、嵌套自动与手动嵌套均符合预期。v0.113.1/v0.111.1 运行与贡献面板视觉未验证。

## 1. 测试目的

验证乱战、惊逃、傻瓜自动打出的牌，其数值写入来源牌行，而不是自动牌自己或能力行。验证嵌套自动归根来源、手动嵌套不继承根来源，以及 `AutoPlayedCount` 持久化。

## 2. 实现要点

- `CombatTracker` 增加 `AsyncLocal` 根来源与卡牌上下文栈；`OnCardPlayStarted(..., isAutoPlay)` 建立自动帧。
- `ResolveSource` 在自动帧内优先返回根来源。
- 自动帧内伤害、修正伤害、升级伤害、格挡、格挡修正、抽牌、能量、星星、治疗、能力施加、Doom 与生成卡来源写根来源。
- 自动牌不创建自己的贡献行；`TimesPlayed` 只统计手动出牌；新增 `AutoPlayedCount`。
- 惊逃补 `AfterAutoPostPlayPhaseEntered` 能力上下文。
- 实际能力 ID 为 `SIMPLETON_POWER`，映射到 `SIMPLEON`；同时兼容旧写法 `SIMPLEON_POWER`。
- `ContributionPersistence`、`RunContributionAggregator` 与 `ContributionChart` 增加 `AutoPlayedCount`。

## 3. 测试方法

测试工程：`8.TEST/1.11.0/AutoPlayProbe/`。

探针在 v0.114.0 首场战斗运行：

1. 对每个源模拟一次手动来源出牌，使能力来源记录到来源卡。
2. 施加乱战、惊逃、傻瓜能力。
3. 添加一张攻击牌到对应牌堆。
4. 调用真实能力 hook，触发真实 `CardCmd.AutoPlay`。
5. 比较根来源伤害与实际敌人 HP + 格挡损失。
6. 检查来源行、自动行、能力行与 `AutoPlayedCount`。

AutoSlayer 的自动出牌用 `AsyncLocal` 测试门阻断，避免污染探针数据。

## 8. 结论

自动出牌根来源汇总的核心路径已验证。用户要求的三张来源牌均通过 v0.114.0 定向测试；无重复行。剩余风险是跨版本运行与 UI 视觉，需要用户实机确认。
