# Stats the Spire 维护项目

本仓库维护 Slay the Spire 2 的本地统计 Mod「Stats the Spire」。源码基线来自作者公开仓库，当前适配游戏 v0.111.1 与 v0.114.0；v0.113.1 只保留历史记录，不属于当前验收基线。本 Mod 代码不发起网络请求；硬依赖 RitsuLib 自身可能发送遥测。

## 文档导航

| 目录 | 内容 |
|---|---|
| `1.PRD/` | 需求、范围、验收 |
| `2.PLANS/` | 施工计划 |
| `3.DOCS/` | 调查结论、测试报告与证据 |
| `4.ADR/` | 技术取舍记录 |
| `5.SDD/` | 系统内部设计 |
| `6.SPEC/` | 对外规范 |
| `7.ChangeLog/` | 版本开发日志 |
| `8.TEST/` | 测试工具、日志与报告 |
| `9.SRC/` | 源码、构建文件与源码说明 |
| `10.OUTPUT/` | 构建产物 |
| `TMP/` | 临时文件登记 |
| `TOOLS/` | 工具登记 |

## 快速构建

```bash
dotnet build 9.SRC/sts2_statsthespire_local.csproj -c Debug
```

详细说明见 `9.SRC/README.md`。
