## 失败与修正

首次探针结果为 `2 PASS / 5 FAIL / 4 SKIP`。失败原因是测试隔离缺陷，不是主 Mod 缺陷：

- v0.111.1 的 AutoSlayer 入口是 `CombatRoomHandler.HandleAsync`，不是 v0.113 的 `PlayCombatAsync`。首次探针没有拦住 AutoSlayer。
- AutoSlayer 在第 3 回合给玩家施加 200 点力量，导致 `howl` 伤害从 18 变为 218、药水伤害异常。
- 修正只在测试探针中进行：拦截 v0.111.1 的 `HandleAsync`；读取可选 JSON 字段时把缺失的 `TimesPlayed` 按 0 处理。
- 修正后探针 6 PASS / 1 FAIL / 4 SKIP；再修正 JSON 可选字段后 7 PASS / 0 FAIL / 4 SKIP。
- 生产代码与 1.13.1 DLL 未修改。

## 数据说明

- 本轮来源数为 35；1.7.0 同种子局的 38 个来源不能直接比较。
- 1.7.0 的 `SHIV` 子行在本轮不再单独出现，数值进入 `CLOAK_AND_DAGGER` 的 `AutoPlayedCount`。这符合 1.11.0 的自动出牌根来源规则。
- 本轮修正伤害总计 2,940，与 1.7.0 同种子局总计相同；但本轮修正伤害落在攻击牌行，而不是 `SPARKLING_ROUGE` 或 `STRENGTH_POWER` 行。原因是 AutoSlayer 的每张牌都走 `CardCmd.AutoPlay`，进入自动根来源路径。该结果不能证明手动出牌时的力量/敏捷归属。
- 启动时出现 `current_run.save` 版本 22 高于 v0.111.1 支持的版本 20 的警告；AutoSlayer 放弃旧局并新建跑局。未手工修改存档。
